# 교대달력 v1.6

기존 v1.5 기반 업데이트. 주·야·비·휴 디자인과 기존 로컬 저장 키를 유지합니다.

- 자원근무 등록 시 주간(07:30–18:00) / 야간(17:30–익일 08:00) 선택
- 월별 자원근무 횟수 및 시간표상 시간 집계
- 2026년 계급별 참고 단가 및 공식 인정시간 입력 시 수당 계산
- 공식 인정시간 미입력 시 **금액 자동 추정하지 않음**: 휴일 인정과 휴게 공제 등 경찰 내부 규칙을 근무표만으로 확정할 수 없기 때문
- 이전 v1.5 데이터 보존, JSON 백업/복원

## 설치
ZIP 내부의 모든 파일을 GitHub Pages 저장소 최상위에 업로드합니다. 서비스워커 캐시가 교체되도록 앱을 재시작하세요. 업데이트 전 JSON 백업 권장.

## 검증
2026년 경사 10월 공식 실적: 시간외 62, 야간 72, 휴일 2 → 1,320,220원(10원 미만 절사).
이 버전은 확정 실적에 대한 금액 산출을 지원하며, 근무표만으로 공식 인정시간을 자동 산출하는 기능은 아직 구현하지 않았습니다.
