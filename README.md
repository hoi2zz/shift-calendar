# 교대달력 v2.4 — 팀별 독립 기록

- 월 제목(2026년 11월) 바로 옆에서 1~4팀 선택
- 팀마다 일정, 메모, 자원근무, 교육시간, 계급, 공식 인정시간을 독립 관리
- 1팀의 기존 기록은 자동으로 1팀에 이관; 2~4팀은 처음에 빈 기록
- 팀별 예상 수당은 해당 팀 근무표와 해당 팀의 기록으로 계산
- JSON 백업은 네 팀 모두 포함; 이전 버전 백업도 1팀 기록으로 복원
- 저장은 사용 중인 브라우저/기기의 localStorage에만 적용. 다른 사람의 기기와 자동 동기화되지 않음
- 2026-11-20 팀별: 1팀 휴무, 2팀 비번, 3팀 야간, 4팀 주간
- 근무시간 및 수당 계산 로직은 v2.3의 잠정 산식을 유지
