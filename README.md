# 교대달력 PWA v1.4

- v1.3의 B형 원형 배지를 차분한 블루그레이 계열로 변경. 주/야/비/휴 문자 구분 유지
- 연가는 따뜻한 베이지, 자원근무는 옅은 파란색 일정 태그로 날짜 아래 표시
- 교육·출장은 회색 태그로 표시, 개인 메모 점 유지
- PNG 이미지 공유에서도 동일한 배지 색과 일정 표시
- 기존 저장 키 `shift-calendar-v1` 및 데이터 구조 유지. 업데이트 전 백업 권장
- `2026-11-21` 주간 기준 주→야→비→휴 자동 계산 유지

압축 해제 후 파일 전체를 GitHub 저장소 루트에 반영하고 GitHub Pages 배포 완료를 확인하세요. PWA가 이전 화면을 보이면 앱을 재실행하고 Safari에서 새로고침하세요.
