# 교대달력 PWA v1.2

## 추가 기능
- 연가·자원근무·근무교환·교육·출장 날짜별 관리
- 자원근무/교환 실제 근무 유형 선택 (기본 주야비휴 순환은 유지)
- 월별 주간/야간/비번/휴무 횟수와 예정 근무시간
- 사용자 입력 월 기준시간 대비 플러스·마이너스 단순 비교 (공식 수당 기준 아님)
- 월간 근무표 PNG 이미지 공유/저장 (iOS 공유 시트 지원 환경)
- 기존 v1.1 `shift-calendar-v1` localStorage 저장값 유지, v1.1 백업 복원 지원

## 배포
압축 해제한 **내부 파일 모두** GitHub `shift-calendar` 저장소 최상위에 덮어쓰기 업로드. Pages 최신 배포 완료 후 앱 재실행. 서비스워커 캐시 갱신에 시간이 걸릴 수 있음.

## 통계 주의
주·야 근무시간 문자열의 처음 두 시각을 사용해 경과시간 계산. 휴게시간/식사시간/공휴일/월별 경찰 수당 규정 반영하지 않음. 연가는 실제 근무 유형 미지정 시 예정시간에서 제외하나, 법정 근무시간/수당 산정과는 다를 수 있음. 근무교환은 각 날짜별 별도 기록.

## 데이터 보호
기기 내 저장, 서버 전송 없음. 브라우저 데이터 삭제 시 소실 가능. 업데이트 전 백업 권장. 실명·사건번호 등 민감정보 기록 금지. 이미지 공유 전 개인정보 확인.
