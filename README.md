# 교대달력 PWA v1.1

## 기준일 검증
2026-11-21 = 주간. 따라서 11/20 휴무, 11/21 주간, 11/22 야간, 11/23 비번, 11/24 휴무, 11/25 주간.

## 업데이트
GitHub `shift-calendar` 저장소 최상위에 이 폴더 내부 파일을 업로드하여 기존 파일을 덮어씁니다. `index.html`, `app.js`, `style.css`, `sw.js`, `shift-core.js` 및 나머지 파일을 함께 올리세요. 배포 후 기존 홈 화면 앱을 완전히 종료하고 다시 실행하거나 Safari에서 새로고침하세요. 서비스워커 업데이트에는 추가 재실행이 필요할 수 있습니다.

## 데이터
기존 localStorage 키 `shift-calendar-v1`을 그대로 사용하므로 동일한 설치/출처 저장 영역에서는 v1 설정과 메모가 유지됩니다. 다른 브라우저 또는 재설치 시에는 데이터가 이전되지 않을 수 있습니다. 설정에서 JSON 백업/복원을 제공합니다. 백업에는 개인 메모가 포함됩니다.

## 테스트
`node test-shift.js` 실행. iPhone Safari 실기기 테스트는 별도로 필요합니다.
