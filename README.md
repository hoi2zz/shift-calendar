교대달력 v1.9

달력 날짜를 누르면 일정·메모 입력창이 즉시 열립니다. 비번/휴무는 배지가 아닌 큰 글씨로 표시합니다. 월별 근무통계 대신 자동 예상 초과근무수당을 표시합니다.

주의: 자동 예상액은 공식 확정액이 아닙니다. 2026년 공휴일 데이터와 가정한 근무시간(정규 야간 14.5시간, 자원 야간 14.5시간)을 사용합니다. 공식 초과근무내역서의 시간외/야간/휴일 실적을 입력하면 별도로 대조할 수 있습니다.

GitHub Pages 저장소 최상위에 압축파일 내 파일을 업로드하세요. 기존 localStorage 키 shift-calendar-v1을 유지합니다.
