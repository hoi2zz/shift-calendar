# 교대달력 PWA v1.0

B 디자인(원형 배지) 기반, 4조 2교대 개인 근무표 PWA입니다.

## 기능
- 주→야→비→휴 순환. 기준일의 근무를 선택하여 과거/미래 계산
- 기준일/근무시간/개인 메모를 localStorage에 저장
- 계정/서버 없이 사용. 서비스워커 캐시 설치 후 오프라인 동작
- 월 이동, 날짜 선택, 개인 메모

## 배포 (컴퓨터 없이 가능)
1. GitHub에서 새 공개 저장소를 생성하고 이 폴더의 **파일들**을 저장소 최상위에 업로드합니다.
2. 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch, main, /(root)를 선택합니다.
3. 배포 주소 `https://사용자명.github.io/저장소명/` 에서 열리는지 확인합니다. 배포 반영에는 시간이 걸릴 수 있습니다.
4. 아이폰 Safari로 해당 HTTPS 주소를 열고 공유 > 홈 화면에 추가 > 추가를 선택합니다.
5. 첫 접속 및 설치 시 인터넷 연결이 필요합니다. 이후 캐시된 버전은 오프라인 사용 가능합니다.

## 주의
- HTML 파일을 파일 앱에서 직접 여는 것으로는 PWA 설치가 되지 않습니다. HTTPS 배포가 필요합니다.
- 메모는 해당 브라우저/기기의 로컬 저장소에만 보관되며 삭제 시 복구할 수 없습니다.
- 근무 변경·교환을 자동 반영하지 않습니다. 메모로만 기록됩니다.
- 현재 알림/이미지 공유/서버 동기화 기능은 없습니다.
- 개인 메모에 민감한 사건 정보나 개인정보를 입력하지 마세요.
- 근무표는 편의용이며 공식 근무명령을 대신하지 않습니다.
